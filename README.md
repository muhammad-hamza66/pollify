# 🗳️ Pollify

A modern full-stack polling platform built with the MERN stack where users can create, vote on, and analyze polls in real time.

![Pollify Banner](./frontend/public/banner.png)

---

## 🚀 Features

- 🔐 JWT Authentication
- 📧 Email OTP Verification
- 🔑 Forgot & Reset Password
- 🗳️ Create Public & Private Polls
- 📊 Live Poll Results
- 💬 Nested Comments
- ❤️ Save/Favorite Polls
- 🔔 Real-time Notifications
- 👤 User Profiles
- 🌙 Dark/Light Theme
- 📈 Poll Analytics
- 🔍 Search & Explore Polls
- 📱 Responsive UI

---

## 🛠 Tech Stack

### Frontend

- React.js
- Vite
- Tailwind CSS
- Axios
- React Router
- Context API

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Bcrypt
- Nodemailer
- Cloudinary
